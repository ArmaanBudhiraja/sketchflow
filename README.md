# SketchFlow

SketchFlow is a browser-based diagramming app for creating flowcharts, UML, ERD, network, and sequence diagrams.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Included Features

- 50+ predefined shapes grouped by category
- Blank and template-based diagrams
- Drag-and-drop shape placement
- Connectors with straight, orthogonal, and curved routing
- Real-time properties panel
- Undo/redo history
- Group, ungroup, align, distribute, and z-order controls
- Browser localStorage save/load/delete
- PNG and SVG export
- Zoom, pan, and keyboard shortcuts
